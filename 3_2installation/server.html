Server Installation

  • Select Installation Type.

  • Launch the TruSmartCAM Installer.

  • In the Installation Type screen:

  • Select Server

  • Click Next.

  • The setup displays the components to be installed:

  • Verify that Install type = Server.

  • Click Install.

  • The installation process starts.

  • The system begins installing TruSmartCAM Prerequisites.

  • In the Select Additional Tasks screen:

  • Install Excel driver.

  • Review the selected additional task.

  • Click Install.

  • The system installs required components such as:

  • Visual C++ Redistributable.

  • .NET Framework.

  • Progress bars will be displayed during installation.

  • Wait until all components are installed.

  • Click Cancel only if you want to abort installation.

  • The system starts installing Microsoft ASP.NET Core Runtime.

  • Wait for the installation to complete automatically.

  • After installation, the Completion Wizard is displayed.

  • Select one of the following options:

  • Yes, restart the computer now (Recommended)

  • No, I will restart the computer later

  • Click Finish.

  • The installer proceeds with TRUMPF LicenseExpert installation.

  • Wait while the setup initializes.

  • In the LicenseExpert configuration screen:

  • Select Set up this computer as license server (for Server setup)

  • If configuring as client (optional case):

  • Select Set up this computer as license client

  • Enter the server name (e.g., LAP730018 or localhost)

  • Click Next.

  • Click Install to proceed.

  • The installer extracts required files.
