Client Installation

Run Prerequisites Installation like Server before beginning the Client setup. Execute Praxis Client installation with the Computer Login User having administrative privileges.

Client Installation

  • Select Installation Type.

  • Launch the TruSmartCAM Installer.

  • In the Installation Type screen:

  • Select Client.

  • Click Next.

  • The setup displays the components to be installed:

  • Verify that Install type = Client.

  • Click Install.

    • Use the same installer that was used for Praxis Server installation. In the client machine, after executing the installer, Select Client option on the component selection page. Pick the required Praxis tools and Click Next.

    • Ready to Install page summarizes the install list. Click Install to proceed with the Installation in Client Machine.

  • The installation process starts.

  • The system begins installing TruSmartCAM Prerequisites.

  • Use same images and information from SERVER installation page…..

  • The License Expert Setup Wizard completes.

  • Click Finish to exit the setup.

  • The installer begins installing the TruSmartCAM Application.

  • Wait for the process to complete.

  • Read the license agreement.

  • Select I accept the agreement.

  • Click Next.

  • Choose Praxis Tools to install or ignore and proceed.

  • Click Next.

  • Select Start Menu Folder:

  • Either choose default or specify different folder for Start Menu Folder.

  • Click Next.

  • Select additional options:

  • Enable Create a desktop shortcut.

  • Click Next.

  • Review selected components.

  • Click Install.

  • Files are extracted and installed.

  • Select Launch TruSmartCAM.

  • Click Finish.

  • Once installation is completed, select Launch Praxis checkbox and Click Finish. When Praxis screen launched, provide the Server name or IP address of Praxis Server PC. .

  • Once connected, Praxis displays the Sign up prompt with programmer permission. Set Email ID, password if needed and click UI:129[OK]. Praxis Library page loads with welcome UserName at the bottom left information area.
